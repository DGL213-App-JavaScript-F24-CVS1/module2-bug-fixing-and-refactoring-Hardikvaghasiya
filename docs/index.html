Tic Tac Toe

A DGL 213 Game

How to play

Goal: The game grid is a 3x3 grid displayed on the canvas.

  • Choose a color by clicking on one of the labeled buttons at bottom of the grid.
  • Player 1 is represented by X (colored red).
  • Player 2 is represented by O (colored blue).
  • The scores of both players are displayed above the canvas.

Player 1 (X): 0

Player 2 (O): 0
